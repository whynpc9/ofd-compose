# Pre-fix spacing paint references

Owned PDFs generated by `FallbackSpacingTests` before the fallback-group fix. Each uses the existing TrueType subset and explicitly placed o/space/f glyphs. Their visual output is the reference; their old high-level extraction is deliberately wrong (extra column separator or missing real boundary space). Tests do not use those old extracted strings as expected text.

The cluster and combining PDFs are pre-fix outputs from `1931647` with the new owned two-glyph probes. Their post-fix rendering must remain pixel-identical.

Semantic cluster/combining/multiple-run references use the pre-fix `ab459d7` writer with the new owned probes.

Mixed-space references use pre-fix `3e62b7b`, before splitting non-space boundaries within mixed text.
