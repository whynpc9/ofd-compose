# 23: 工作台：页面/样式/表格设计

**What to build:** 模板作者在工作台中设置纸张、方向、页边距，编辑样式表，插入并编辑表格（合并单元格、列宽、行高、边框、背景、垂直对齐），配置页眉页脚（页码、起始页码、指定页隐藏、页面边框）与文字/图片水印，声明跨页重复表头；所有设置保存进自有 Document Model 并可被 Layout Core 消费。

**Blocked by:** 22 工作台壳 + Editor Adapter

**Status:** ready-for-agent

- [ ] 页面/节设置面板；物理单位输入
- [ ] 样式表编辑与应用
- [ ] 表格编辑：插入/删除行列、合并、列宽、行高、边框、背景、垂直对齐；标记表头行（跨页重复）与"表头与首行同页"
- [ ] 页眉页脚编辑与页码域插入；指定页隐藏；页面边框
- [ ] 水印配置（文字/图片、透明度、层级）
- [ ] 段落属性：标题与下段同页、孤行控制、固定区域及其溢出策略
- [ ] 上述内容 round-trip 无损；Editor Adapter 支持清单相应扩展并有测试
